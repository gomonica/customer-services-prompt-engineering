# customer-services-prompt-engineering
This repository contains prompt engineering examples for customer service in various case
## Objectives
- Design effective prompts for customer service tasks.
- Compare prompt versions and improve response quality.
- Document prompt evaluation and refinements.
## Scenarios
- FAQ
- Refund Request
- Shipping Delayed
- Customer Complaint
- Order Tracking
## Skills Demonstrated
- Prompt engineering
- Instruction writing
- Response evaluation
- Prompt refinement
